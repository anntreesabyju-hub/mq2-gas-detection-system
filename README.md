# MQ2 Gas Detection System

## Description
This project uses an MQ2 gas sensor with Arduino Uno to detect harmful gases.

## Components Used
- Arduino Uno
- MQ2 Gas Sensor
- LED
- Buzzer

## Features
- Gas leakage detection
- LED warning indication
- Buzzer alert system

## Software Used
- Arduino IDE
